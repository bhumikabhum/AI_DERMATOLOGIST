# AI_DERMATOLOGIST
# 🌿 DermaNav+ — AI-Powered Skin Disease Detection

> An intelligent web application that detects and classifies **skin diseases** from images using **MobileNetV2 (Transfer Learning)**.  
> Built with **React.js, Node.js, Flask (Python)**, and **TensorFlow**.

---

## 🧠 Overview
**DermaNav+** helps users analyze skin conditions by uploading an image.  
It predicts diseases like:
- Melanoma  
- Eczema  
- Rosacea  
- Basal Cell Carcinoma  
- Acne Vulgaris  
- Normal Skin  

Each prediction includes **disease description, precautions, and treatment advice**.
